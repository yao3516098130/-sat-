用户输入数字并回车，选择对应功能；
菜单选项说明：
1 — 输入一个CNF文件名，并读取 CNF 文件
2 — 遍历打印读取的 CNF 所有子句
3 — DPLL 求解（基准版 + 可选优化版），可保存求解结果
4 — 进入星形数独游戏模块
0 — 释放内存，退出程序
具体如下

功能 1：Open the CNF file（读取 CNF 文件）
1. 在主菜单输入1回车。
2. 若已经加载过 CNF 文件，程序提示The CNF has been read. Do you want to read another? (1/0):
◦ 输入0：不更换文件，返回菜单
◦ 输入1：自动释放当前 CNF 链表内存，准备读取新文件
3. 提示Please input the cnf file name:，输入 CNF 文件名（文件需要放在 exe 同一目录下，支持填写完整路径），回车。
4. 提示Read cnf file successfully.代表解析成功；提示Read cnf file failed.代表文件不存在或格式错误，返回主菜单。
注意：必须加载 CNF 文件后，才能执行选项 2、选项 3。

功能 2：Traverse and output each clause（打印 CNF 子句）
1. 主菜单输入2回车。
2. 如果没有加载 CNF，提示You haven't open the CNF file.，返回菜单。
3. 已加载 CNF：控制台依次输出全部子句内容，查看解析后的合取范式。

功能 3：Solve using DPLL and save the result（DPLL 求解与结果保存）
1. 主菜单输入3回车。未加载 CNF 会提示并返回菜单。
2. 程序先运行基准版 DPLL（flag=1），使用 Windows 高精度计时器自动计时：
◦ 输出 SAT/UNSAT 结果；SAT 时输出每个变量的 TRUE/FALSE/UNASSIGNED 赋值
◦ 输出递归次数Recursion count、基准求解耗时Time: xx ms (not optimized)
3. 提示Do you want to run optimized DPLL(flag=2/3)? (0/2/3):
◦ 输入0：不运行优化版本，直接进入结果保存选择
◦ 输入2或3：执行对应 flag 的优化 DPLL（MOMS 分支策略），重置递归计数器，输出优化后的递归次数、耗时、优化率。优化率计算公式：[(基准耗时−优化耗时)/基准耗时]×100%，负值代表优化策略在该算例性能下降。
4. 提示Save the result to output file? (1/0):
◦ 输入0：不保存，释放内存，返回主菜单
◦ 输入1：输入输出文件名（例如 out.res），程序将 SAT/UNSAT 状态、变量赋值、基准耗时、优化耗时、优化率、递归次数写入该文本文件。提示Save result successfully即保存完成。

功能 4：Asterisk-Sudoku game module（星形数独模块）
1. 主菜单输入4回车。
2. 调用X_Sudoku()函数，进入星形数独子菜单。
3. 在数独子界面可实现：1.自动生成星形数独终盘
                                   2.支持玩家手动输入行列 + 数字进行交互式填数，实时游玩数独。
                                   3.调用 DPLL 自动求解数独，并输出数独答案。
                                   4.退出该功能。
4. 操作完成后，返回 SAT 系统主菜单。

功能 0：EXIT（退出程序）
主菜单输入0，程序自动释放 CNF 链表内存，安全退出，避免内存泄漏。
